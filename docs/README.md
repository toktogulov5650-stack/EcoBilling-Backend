# Документация EcoBilling

Документация описывает только фактически реализованное поведение. Наличие доменной модели или таблицы не означает наличия пользовательского HTTP-сценария.

- [Статус проекта](project-status.md) — реализованный объём, ограничения и отложенные сценарии.
- [Архитектура](architecture/README.md) — границы, зависимости, ADR и открытые решения.
- [Бизнес-правила](business-rules/README.md) — только подтверждённые правила предметной области.
- [API](api/README.md) — текущая HTTP-поверхность и внутренний контракт.
- [База данных](database/README.md) — схемы PostgreSQL, ограничения и миграции.
- [Конфигурация](configuration/README.md) — обязательные параметры, секреты и переменные окружения.
- [Тестирование](testing/README.md) — локальные и CI-проверки, включая PostgreSQL и E2E.
- [Развёртывание](deployment/README.md) — контейнерный стек одного округа.
- [Эксплуатация](operations/README.md) — запуск, диагностика, обновление и ограничения rollback.
- [Production readiness checklist](operations/production-readiness.md) — проверяемый go/no-go список для конкретного окружения.
- [Безопасность и готовность](security/README.md) — защитные меры, остаточные риски и production release blockers.

Если документация расходится с production-кодом, миграциями или исполняемыми тестами, это считается дефектом и должно исправляться явно. Неподтверждённые правила нельзя маскировать примерами, значениями по умолчанию или обещанием готовой функции.
