# ADR-0002: принадлежность экземпляра одному округу

- Статус: принято
- Дата: 2026-09-24

## Контекст

Каждый округ имеет отдельные экземпляры EcoBilling.Api, EcoBilling.Worker и PostgreSQL. Перед входом EcoBilling.Control разрешает введённый пользователем код округа в адрес соответствующего API.

## Решение

Код округа является свойством развёрнутого экземпляра и поступает из доверенной конфигурации. Он не дублируется в `Users`, `Residents` или `Employees` как `DistrictCode` или `DistrictId`.

После разрешения кода клиент обращается напрямую к найденному EcoBilling. Если код нужно показать пользователю, API читает его из конфигурации экземпляра.

## Последствия

- Локальные запросы не требуют фильтрации строк по округу.
- Изоляция округов обеспечивается развёртыванием, базой данных и конфигурацией.
- Подмена конфигурации экземпляра является операционным риском и должна контролироваться средствами развёртывания.
