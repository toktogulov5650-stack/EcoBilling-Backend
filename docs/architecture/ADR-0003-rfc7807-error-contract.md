# ADR-0003: формат HTTP-ошибок RFC 7807

- Статус: принято
- Дата: 2026-09-24

## Контекст

Клиентам требуется единый машинно-читаемый формат ошибок без раскрытия внутренних деталей реализации.

## Решение

HTTP API использует RFC 7807 Problem Details. Помимо стандартных полей контракт содержит устойчивые расширения:

- `code`;
- `traceId`;
- `validationErrors` только для ошибок проверки входных данных.

Отдельный произвольный DTO ошибок не используется. Наружу не возвращаются stack trace, SQL, внутренние исключения и секретные значения.

## Последствия

- `Error.Code` в SharedKernel предоставляет устойчивый прикладной код.
- Преобразование `ErrorType` в HTTP status и Problem Details относится к будущему API-слою.
- Тексты ошибок можно изменять или локализовать без изменения машинного контракта.
